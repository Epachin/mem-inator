# Мемоинатор

Нативная мем-лаборатория для Android 7.0 и новее. Для входа используется локальный аккаунт. Фотографии и подписи обрабатываются на устройстве. Пользователь сам выбирает приложение-получатель при отправке PNG.

## Аккаунты и сессии

Аккаунты доступны только на устройстве, где они созданы. На первом запуске выберите «Регистрация». В дальнейшем для входа подходят имя пользователя и email без учёта регистра. Активная сессия хранится отдельно в таблице Session базы Room и восстанавливается при запуске. «Выйти» завершает её и возвращает экран входа.

Таблица Account хранит хеш PBKDF2, индивидуальную случайную соль (16 байт), название алгоритма и число итераций. На Android 8 и новее применяется HMAC-SHA-256 с 600 000 итераций, на Android 7 — HMAC-SHA-1 с 1 300 000. Поля паролей живут только в памяти. В профиле доступны смена имени, email, пароля и фото. Для смены email и пароля требуется текущий пароль. Нажмите на аватар, чтобы выбрать фотографию. Выбранное изображение копируется в закрытую папку avatars.

Каждый аккаунт видит собственные мемы. При обновлении базы с версии 1 до 2 старые записи и PNG сохраняются. Мемы из прежней версии получает первый зарегистрированный на устройстве пользователь.

## Экраны

- **Главная** открывает редактор с чёрно-белым котом, системный выбор фотографии или каталог.
- **Шаблоны** показывают встроенную цветную и монохромную версии фотографии кота, затем сетевую коллекцию. Нажатие на карточку открывает редактор.
- **Создание мема** позволяет заменить изображение, ввести две подписи и изменить размер шрифта. Длинные подписи переносятся и при необходимости уменьшаются. «Сгенерировать мем» сохраняет PNG и возвращает на главную. Кнопка «Перейти» в уведомлении открывает всю коллекцию. Меню отправки открывается по кнопке «Поделиться PNG».
- **Мои мемы** показывает коллекцию из Room. Поиск учитывает название и дату в формате ДД.ММ.ГГГГ, а фильтр «Недавние» охватывает последние семь дней. Сердце на карточке сохраняет мем в избранном. В меню ⋮ можно отправить PNG или открыть редактируемый мем. При сохранении изменений обновляется та же карточка. Нажмите карточку, чтобы открыть PNG, отправить его или подтвердить удаление. Системная кнопка «Назад» возвращает из редактора или просмотра на предыдущий экран.

- **Профиль** показывает число мемов в архиве, карточку первого эксперимента и настройки оформления. Выбранная тема сохраняется при перезапуске.

В нижней панели три вкладки: «Главная», «Мои мемы» и «Профиль». Каталог открывается с главной кнопкой «Каталог шаблонов».

## Запуск и сборка

Откройте корневую папку с файлом `settings.gradle.kts` в Android Studio с поддержкой Android Gradle Plugin 9.5.2. Установите SDK Platform 37 и примите лицензии SDK. Проект использует Gradle Wrapper 9.6 и JVM 25 для Gradle Daemon. При первой синхронизации требуется интернет. Выберите модуль app и устройство с API 24 или выше.

В PowerShell выполните:

```powershell
.\gradlew.bat assembleDebug assembleRelease
.\gradlew.bat installDebug
```

APK находятся в `app/build/outputs/apk/debug/` и `app/build/outputs/apk/release/`. Для release включён R8 через `isMinifyEnabled = true`. Таблица переименований для расшифровки стеков конкретной сборки находится в `app/build/outputs/mapping/release/mapping.txt`. Для распространения подпишите release APK собственным ключом через Android Studio. Локальные настройки SDK, ключи и результаты сборки исключены из Git.

## Устройство проекта

Исходники находятся в `app/src/main/java/com/example/memoinator_final_build/`.

| Файл | Назначение |
|---|---|
| MainActivity.kt | Экраны Compose, маршруты Navigation Compose, Photo Picker и Sharesheet |
| Studio.kt | AndroidViewModel, состояние StateFlow, сеть, загрузка изображений, сущность и DAO Room |
| Renderer.kt | Раскладка текста StaticLayout, контур и заливка, отрисовка MemePreview |
| GenerateMemeButton.kt | Анимированная кнопка |
| ui/theme/ | Цвета, формы и типографика Material 3 |

Редактор рисует изображение и обе подписи в одном Bitmap. Предпросмотр масштабирует этот Bitmap, а экспорт записывает его в PNG. Room хранит UUID, заголовок и время создания в `lab.db`. Начиная со схемы Room 3 приложение сохраняет исходное изображение без подписей в files/sources и хранит тексты и размер шрифта в базе. При миграции существующие мемы получают пустую отметку избранного. Карточки с одним готовым PNG поддерживают просмотр и отправку. Постоянные PNG находятся в `files/memes/`, временные файлы для отправки из редактора — в `cache/exports/`. Получатель получает временный доступ через FileProvider. При удалении приложение убирает запись Room и файл изображения.

## Каталог и встроенные изображения

Приложение выполняет HTTPS GET, проверяет флаг `success` и читает `name` и `url` из массива `data.memes`. Загрузка каталога и загрузка отдельных изображений имеют отдельные состояния ошибки и повторные попытки. Встроенные шаблоны доступны сразу. [API Imgflip](https://api.imgflip.com/get_memes)

Автор встроенной фотографии — **Fir0002/Flagstaffotos**. Цветной шаблон использует оригинал, монохромный применяет обесцвечивание. [Фотография и условия использования](https://commons.wikimedia.org/wiki/File:Cat03.jpg) · [GNU FDL 1.2](https://www.gnu.org/licenses/old-licenses/fdl-1.2.html)

## Достижения

Нажмите на панель достижений в профиле, чтобы открыть десять целей и даты их получения. Схема Room 4 хранит события и награды отдельно для каждого аккаунта. Удаление мема сохраняет заработанные достижения. При обновлении учитываются сохранившиеся мемы, отметки избранного, признаки редактирования и установленный аватар. Если время прежнего действия неизвестно, датой получения считается дата начисления при обновлении.

## Как настроить анимацию кнопки

Компонент находится в `app/src/main/java/com/example/memoinator_final_build/GenerateMemeButton.kt`.

| Параметр | По умолчанию | Действие |
|---|---|---|
| interval | 2500 мс | Длительность светового блика между вспышками искр |
| duration | 400 мс | Длительность встряхивания и искр |
| amplitude | 4 dp | Максимальное горизонтальное смещение |
| sparkColor | #7BFF95 | Цвет искр |

Animatable задаёт общую фазу для смещения graphicsLayer и линий Canvas поверх кнопки. Геометрия соседних элементов сохраняется. Цикл привязан к состоянию RESUMED, учитывает доступность кнопки и системный масштаб анимации.

## Сценарий демонстрации

1. Откройте главную и подождите три секунды. Посмотрите на смещение кнопки и зелёные искры.
2. Перейдите в «Шаблоны», выберите кота. Введите длинную кириллическую подпись, передвиньте ползунок, сохраните мем.
3. На главной нажмите «Перейти» в баннере сохранения. Откройте карточку в «Моих мемах» и сравните изображение с предпросмотром. Нажмите «Поделиться PNG» и вернитесь из системного меню.
4. Включите авиарежим, закройте приложение и запустите снова. Откройте сохранённую работу. Удалите её и проверьте пустое состояние.
5. Откройте каталог без сети и повторите загрузку. Создайте ещё один мем по встроенному шаблону. На главной через «Своё фото» выберите фотографию устройства.
